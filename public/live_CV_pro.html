BATTLE SCARS (real production incidents — SYMPTOM / CAUSE / FIX)

The Ghost Worker Uprising

[CRITICAL] Scout v0.24

Badges: worker_threads · Playwright · Session Lifecycle

SYMPTOM: Browser windows kept reopening and closing in a loop after "Stop Agent" was clicked, even though the UI showed IDLE.

CAUSE: Session.stop() flipped state to STOPPED but never terminated the background node:worker_threads; when the browser

context closed, Playwright errors triggered RecoveryManager to relaunch, spawning zombie workers.

FIX: Added Executor.terminateAllWorkers() to force-kill active worker threads on stop/restart, plus a STOPPED guard check at the top

of every brain cycle.

The Ghost Match Massacre

[CRITICAL] Logic Arena v2.5.0

Badges: WebSocket · NestJS · Memory Leak

SYMPTOM: Server kept executing MOVE_FAST for disconnected players, pinning CPU at 100%.

CAUSE: WebSocket dropped on disconnect but the MatchEngine physics loop kept running indefinitely, accumulating hundreds of dead

matches.

FIX: Tied match lifecycle to connected client count — numClients === 0 calls match.stop() and destroys engine from RAM.

The Ghost Robot Infestation

[CRITICAL] Logic Arena v3.5.0

Badges: R3F · WebSocket · State Management

SYMPTOM: After rapid arena switching, robots from previous match appeared as invisible ghosts; on third switch nothing worked at all.

CAUSE: Module-level InterpolationBuffer singleton never cleared between matches; stale selectedRobotId/socketUserId refs silently

rejected by server.

FIX: Added clear() on arena mount/unmount, reset all tracking refs in useGameState, replaced Link back buttons with router.push()

emitting leaveMatch before navigation.

The Mobile Scroll Lag Catastrophe

[HIGH] Logic Arena v3.2.0

Badges: 3D Performance · CSS · Mobile

SYMPTOM: Scrolling the landing page and dashboard on mobile was severely stuttery, especially on mid-range Android devices.

CAUSE: A triple performance cascade: 3D background objects were recreated every frame (GPU memory churn), backdrop-blur forced

a full-viewport compositor repaint on every scroll frame, and theme CSS transitions fired mid-scroll causing frame drops.

FIX: Wrapped 3D objects in useMemo (created once), removed backdrop-blur on mobile in favor of solid backgrounds (highest-impact

fix), globally disabled CSS transitions during theme changes, and added an IntersectionObserver to pause 3D rendering when the

canvas scrolls out of view.

The LAVA/ICE Damage Double-Stack

[HIGH] Logic Arena v3.2.0

CAUSE: Static CYBER-theme lava obstacles were leaking into LAVA/ICE maps and applying damage simultaneously with the dynamic

LAVA_POOL obstacles; rotated obstacle hitboxes also used AABB collision, extending well past their visual boundary.

FIX: Removed static lava obstacles on LAVA/ICE themes to eliminate double-stacking, and upgraded TRAP/LAVA collision from AABB
